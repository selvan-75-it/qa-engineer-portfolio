# 🐞 Bug Reports

## 1. Purpose

This directory contains verified defects identified during testing of the SauceDemo practice application.

Each defect must be:

- Reproducible
- Clearly documented
- Supported by an expected vs actual comparison
- Assigned an appropriate Severity
- Assigned an appropriate Priority
- Supported by evidence where applicable

---

# 2. Bug Lifecycle

```text
Defect Suspected
      ↓
Reproduce
      ↓
Verify
      ↓
Document
      ↓
Assign Severity
      ↓
Assign Priority
      ↓
Report
      ↓
Fix
      ↓
Retest
      ↓
PASS → Close
  │
  └── FAIL → Reopen
